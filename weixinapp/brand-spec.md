# brand-spec — 《两个人的小世界》情侣微信小程序

**来源：** 用户提供的 5 张高保真页面截图（程序抽样提取主色）+ PRD §4.1 视觉基准。
截图主色抽样（量化后按占比排序）：`#F0F0E0`（纸底）、`#F0E0D0`（蜜桃纸卡）、`#F0E0E0/#F0F0D0/#F0E0C0`（粉/黄纸卡）、`#504040`（深暖灰文字）、`#F0A090`（珊瑚粉强调色）、`#D0E0F0/#E0E0F0`（雾蓝功能色）。

## 六个核心 Token（OKLch）

| Token | OKLch | 抽样来源 |
|---|---|---|
| `--bg` | `oklch(0.955 0.013 100)` | #F0F0E0 暖米白纸底 |
| `--surface` | `oklch(0.93 0.024 72)` | #F0E0D0 蜜桃纸片卡片 |
| `--fg` | `oklch(0.36 0.014 25)` | #504040 深暖棕灰 |
| `--muted` | `oklch(0.54 0.022 55)` | 暖棕灰次级文字 |
| `--border` | `oklch(0.898 0.02 85)` | 纸纹浅棕描边 |
| `--accent` | `oklch(0.772 0.088 35)` | #F0A090 珊瑚粉主按钮 |

## 功能色（PRD 指定：低饱和粉、蓝、绿、橙）

- 粉 `oklch(0.78 0.07 10)` — 爱心、约会心形标记、点赞
- 蓝 `oklch(0.79 0.05 250)` — 待办圆点、天气、位置
- 绿 `oklch(0.79 0.055 140)` — 「好好吃饭」模块
- 橙黄 `oklch(0.84 0.09 85)` — 纪念日星星、太阳装饰
- 纸色卡：蜜桃 / 粉 / 蓝 / 绿 / 黄，全部由上述 token 经 `color-mix` 派生，不新增裸色值。

## 字体栈

- **Display（手写标题）**：`'Ma Shan Zheng','Kaiti','STKaiti','KaiTi',cursive`（Google Fonts 马善政楷体，离线回退系统楷体）
- **Body（正文）**：`-apple-system,'PingFang SC','HarmonyOS Sans SC','Microsoft YaHei',system-ui,sans-serif`
- **Mono（数字/时间戳）**：`ui-monospace,'Cascadia Mono',Menlo,monospace`，大数字用 tabular-nums

## 视觉语言规则（截图观察）

1. **纸片手账**：暖米白纸上铺大圆角（16–24px）低饱和纸色卡片，细手绘感描边，留白充足，一卡一功能。
2. **手写标题 + 口语文案**：标题用手写体并缀 ❤️；按钮文案口语化（提醒 TA / 想你了 / 添加约会），禁用「提交」「确定」等系统腔。
3. **珊瑚粉单一主按钮**；功能色各司其职：粉=爱/约会、黄=纪念日、蓝=待办/天气、绿=吃饭。
4. **手绘 IP 与涂鸦**：情侣角色头像、爱心、花草、太阳、猫咪等手绘装饰贯穿页面，营造恋爱手账氛围。
5. **轻量弹性动效**：点击缩放、心情卡弹跳、爱心飞出、铃铛摇晃、日历月份滑动；Loading 用小太阳旋转。

**一句话总结：** 恋爱手账风的微信小程序——暖米白纸底铺低饱和蜜桃纸片卡片，珊瑚粉主按钮，手写体标题配手绘情侣 IP，温暖治愈、轻互动、低压力。
